
# DESCRIPTION

The AKS-74U and the BS-1 "Tishina" Grenade Launcher.
This mod changes the AKS-74U with a much better model, textures and animations!
It also adds the BS-1 "Tishina" Grenade Launcher, this is a very unique and particular Silenced Grenade Launcher that was made to be equipped on an AKM, to fire 30mm VOG-T grenades, and then adopted for the AKS-74UB.
The new unique, incredible animation set is made by "Firebreath".
All changes to textures made by "Blackgrowl".

# INSTALLATION

The mod was made with FOMOD in mind, it's recommended you use Mod Organizer 2 (MO2). If not, manual:
Simply extract the "gamedata" to your main Anomaly folder.
Look for addons in "addons", extract gamedata from it to your main Anomaly folder.

# DETAILS

Model-wise:
The AKS-74U is made by "luchadordev", it comes with some very nice Mesh & Texture details.
The "BS-1 Tishina Grenade Launcher" is from "Caliber", all credits go to them.

Texture-wise:
Textures modified and improved by "Blackgrowl" to look better in STALKER.

Animation-wise
Completely new unique animation set by "FireBreath", includes Inspect/Idle/Bore, Jam Inspect, Unjam, Magazine Check as well as Full & Partial Reload.

Balance-wise:
There are no balance changes whatsoever, other than the addition of a Grenade Launcher for the AKS-74u.

# COMPATIBILITY

Not compatible with mods that change "w_aks74u.ltx"
